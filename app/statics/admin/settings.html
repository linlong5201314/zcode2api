鉴权
用于登录管理后台。留空可退回“仅密码”模式；推荐保持账号密码双因子式入口。
用于登录此管理后台。修改后需用新密码重新登录。
设置后，调用 /v1/messages 须携带 Authorization: Bearer <key> 或 x-api-key。为避免误操作，留空表示保持当前值。
后台自动刷新各账号额度与状态的周期。设为 0 关闭自动刷新（仍可手动刷新）。修改后即时生效。
使用说明
· 在「账号池」粘贴编程套餐令牌（JWT）或接口密钥即可加入轮询。
· 请求按顺序轮询分发；某账号额度用完会自动切换到下一个账号。
· 账号额度、状态在「账号池」页实时刷新展示。
· 出口代理在「代理设置」页配置，云端部署绕过 IP 风控。
· Anthropic 端点：/v1/messages
· OpenAI 端点：/v1/chat/completions（兼容 Cherry Studio / LobeChat / NextChat 等客户端，支持流式与 token 用量统计）
· Responses 端点：/v1/responses（Codex CLI / 新版 OpenAI SDK 可直连）。
